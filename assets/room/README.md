# ROOM 가구 PNG 넣는 방법

1. **PNG 파일을 이 폴더(`assets/room/`)에 넣는다.** 파일 이름 = 가구 아이디 (영문 소문자·숫자·밑줄만).
   - 예) `bed_basic.png`
2. **색상 변경이 되는 가구**는 같은 크기의 마스크 PNG를 하나 더 넣는다: `bed_basic_mask.png`
   - 마스크 = 색이 바뀌어야 하는 부분만 **흰색**, 나머지는 **투명**으로 칠한 그림 (크기는 본 그림과 정확히 같게).
   - 본 그림에서 그 부분은 **밝은 회색/흰색 계열**로 그려야 고른 색이 예쁘게 입혀진다 (색 × 밝기로 곱해진다).
   - 마스크가 없으면 색상변경 버튼은 꺼진다.
3. **`js/data.js` 의 `ROOM_FURNITURE` 표에 한 줄 추가한다.** (다른 파일은 안 건드려도 된다)
   ```js
   ['bed_basic', '침대', '기본 침대', '포근한 침대다.', { mask: true }],
   ['clock_round', '벽소품', '둥근 시계', '벽에 거는 시계다.'],
   ['plant_small', '소품', '작은 화분', '귀여운 화분이다.', { scale: 4 }],   // 16×16 도트를 4배로
   ```
   - 분류: `침대` `의자` `책상` `수납` `소품` `벽소품` (벽소품은 자동으로 항상 바닥 가구 뒤에 놓인다)
   - 옵션: `mask:true`(색상변경) · `scale`(그림을 몇 배로 보여 줄지, 기본 1) · `layer:'wall'`(분류와 상관없이 벽 층으로)
4. 끝. 새로고침하면 편집 화면의 해당 분류 칸에 나타난다.

## 그림 크기 가이드
- 방 무대는 600×600, 바닥 마름모 가로 500. 그림은 **보이는 크기 그대로** 그리면 된다 (기본 `scale:1`, 가로 40~200px 정도).
- 작은 도트 그림(예: 16×16)은 `scale:4` 처럼 키우면 도트가 선명하게 유지된다 (확대 시 `pixelated`).
- 투명 배경 PNG 사용. 파일 하나는 가급적 50KB 이하 (세이브에는 좌표만 저장되고 그림은 저장되지 않는다).
- 아이디를 한 번 정하면 바꾸지 않는다. 바꾸거나 삭제하면 그 가구를 놓아 둔 대원의 방에서 그 가구만 사라진다.

## 확인
`python3 tests/room_test.py` (가구 PNG 불러오기·색상·저장 검증이 들어 있다).

# 벽지 · 바닥 · 배경 틀 직접 그리기

세 가지 모두 **600×600 PNG 한 장**이다. 방 무대와 같은 좌표라서, 안내 그림 **`_guide_room.png`**(방 모양·좌표 눈금이 그려진 그림)를 맨 밑 레이어로 깔고 그 위에 그린 뒤, 안내 레이어는 지우고 저장하면 된다.

| 종류 | 그릴 자리 | 나머지 | 파일 |
|---|---|---|---|
| 벽지 | 왼쪽 벽 + 오른쪽 벽 (두 평행사변형) | **투명** | `assets/room/<아이디>.png` |
| 바닥 | 바닥 마름모 | **투명** | `assets/room/<아이디>.png` |
| 배경 | 600×600 전체 | 불투명 | `assets/room/<아이디>.png` |

방 모양 꼭짓점(600×600 안의 좌표):
- 왼쪽 벽: (50,225) (300,100) (300,250) (50,375)
- 오른쪽 벽: (300,100) (550,225) (550,375) (300,250)
- 바닥: (50,375) (300,250) (550,375) (300,500)
- 벽 두 면이 만나는 세로 모서리는 x=300, 벽과 바닥의 경계는 위 좌표의 아랫변이다. 벽지와 바닥은 서로 겹쳐도 된다 (바닥이 벽지 위에 그려진다).
- 벽에 거는 소품·가구는 이 위에 놓이므로, 그림 안에 가구를 그리지 않는다.

등록은 `js/data.js` 의 `ROOM_SKIN_PNG` 표에 한 줄:
```js
['wall_stripe', '벽지', '줄무늬 벽지', '산뜻한 줄무늬 벽지다.'],
['floor_tile',  '바닥', '타일 바닥',   '차가운 타일 바닥이다.'],
['bg_sky',      '배경', '구름 하늘',   '구름이 흐르는 하늘이다.'],
```
- 벽지/바닥/배경 탭에 칸이 생긴다. 칸의 작은 그림은 파일에서 자동으로 잘라 보여 준다.
- 벽지·바닥 PNG는 색상 변경이 없다 (색을 바꾼 버전이 필요하면 파일을 따로 그려 한 줄 더 추가).
- 기본으로 들어 있는 색 벽지/바닥/배경(크림·하늘 등)은 그대로 있고, PNG와 섞어 고를 수 있다.
